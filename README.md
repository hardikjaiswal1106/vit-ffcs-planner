# VIT FFCS Planner — 4th Sem (Vellore)

Fully-offline timetable planner for VIT Vellore FFCS. No backend, no login — just open `index.html`.

## Courses loaded

| Code | Course | Type |
|------|--------|------|
| MOC  | Models of Computation | Theory only |
| SE   | Software Engineering | Theory + Lab |
| AIML | Fundamentals of AIML | Theory + Lab |
| FS   | Full Stack | Theory + Lab |

## Features
Same engine as 3rd sem: faculty priority (search + drag-reorder), Generate builds up to 50 clash-free combinations, inline clash-reason pills when a course can't be placed, free-day count (no lab that day), PNG export, auto-save.

## Run it
Just open `index.html` in any browser. No build step.
